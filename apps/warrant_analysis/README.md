# Warrant Analysis App

CA MUTCD 2026 Traffic Signal Warrant Analysis — Streamlit app.

## Setup
```bash
pip install -r requirements.txt
```

## Run
```bash
streamlit run 26warrant_app.py
```

## References
Place `camutcd-2026-4c.pdf` in a `references/` subfolder next to this file.
Thresholds per CA MUTCD 2026, Chapter 4C.
